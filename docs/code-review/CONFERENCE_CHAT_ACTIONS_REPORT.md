# Действия с чатами конференций

Дата: 6 октября 2026 года.

## Что реализовано

- В списке `/conferences` у каждой встречи появилось меню: информация о чате,
  переключение уведомлений, добавление участников, выход из чата.
- Окно информации показывает название, описание, ссылку на видеовстречу,
  количество участников и персональный переключатель уведомлений.
- В окне доступны поиск по переписке, участники, картинки, файлы, ссылки и
  важные сообщения. Поиск и списки загружаются ограниченными страницами.
- Организатор может менять название и описание. Приглашения используют
  существующую форму email и выбора зарегистрированных пользователей.
  Остальные участники могут скопировать публичную ссылку.
- Важные сообщения сохраняются как личные отметки. Они не видны другим
  участникам. Результат поиска открывается в контексте нужного сообщения,
  включая завершённую конференцию.
- Файлы открываются через существующий механизм авторизации и временных
  подписанных ссылок. Срок действия ссылки учитывается в интерфейсе.
- Новое сообщение создаёт уведомление в личном кабинете получателя.
  Отключение уведомлений и выход учитываются при формировании и доставке.
  Для сообщений не создаются дополнительные письма.
- Выход подтверждается отдельно и действует только для текущего пользователя:
  чат скрывается из его списка, доступ и уведомления прекращаются. Встреча,
  история, записи и полномочия организатора сохраняются. Явное подключение по
  ссылке возвращает пользователя; повторное приглашение само не отменяет выход.
- Пункт «Пожаловаться» отсутствует.

## Реализация

Миграция `000029_conference_chat_actions.up.sql` добавляет описание,
персональные настройки, отметки сообщений, индекс поиска и ограниченную
очередь уведомлений. Предыдущие миграции сохраняются без изменений.

Новые маршруты находятся в `/api/v1/conferences/:id/chat`. Сервер проверяет
авторизацию, членство и область конференции для информации, участников,
поиска, материалов и отметок. Изменение названия разрешено организатору.
Настройки и отметки разделяются по текущему пользователю. Существующие
подключения отзываются после выхода из чата.

## Проверки

- TypeScript и 45 тестов интерфейса — PASS: меню, информация, настройки,
  личные отметки, ошибки сервера, переход к сообщению и подтверждение выхода.
- Playwright: реальный интерфейс с изолированными API-данными, desktop,
  ширина 390 и 320 px, клавиатура, возврат фокуса, доступность модального окна.
- PostgreSQL: отдельная тестовая база с миграцией 29, поиск, личные отметки,
  уведомления, выход и повторное подключение.

Серверные интеграционные проверки также подтвердили отказ постороннему
пользователю, недоступность отметок и контекста другой конференции, отсутствие
уведомлений самому отправителю и гостям, постраничную выдачу материалов без
потери элементов и сохранение данных при миграции. Тесты выполнялись в
отдельных временных базах; реальные письма не отправлялись.
