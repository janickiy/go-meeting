# Административная сводка и возможности продукта

Этап 9 добавляет глобальное право администратора отдельно от ролей встречи. `owner` и `co_host` управляют своей конференцией, но не получают доступ к административной сводке.

## Назначение права

Миграция `000021_admin_capability.up.sql` добавляет `users.is_admin BOOLEAN NOT NULL DEFAULT FALSE`. Регистрация всегда создаёт обычного пользователя. После создания учётной записи оператор назначает право по **проверенному UUID** через доверенную SQL-консоль:

```sql
UPDATE users SET is_admin = TRUE WHERE id = '<user-uuid>';
```

Для снятия права установите `FALSE`. API проверяет текущее значение в PostgreSQL на **каждом** запросе `/api/v1/admin/*`; ранее выданный JWT сразу теряет административный доступ. Права нельзя назначить через клиентский запрос или роль конференции. Операцию выдачи/отзыва следует фиксировать в журнале доступа к БД: в приложении нет отдельного журнала администраторских назначений.

## HTTP-контракт

Оба маршрута требуют Bearer JWT. Ответы имеют `Cache-Control: private, no-store` и `X-Content-Type-Options: nosniff`.

- `GET /api/v1/capabilities` возвращает `capabilities` с `liveCaptions`, `transcription`, `aiSummary`, `semanticSearch`, `meetingAnalytics`, `recordingModes` и безопасный `buildVersion`. Семантический поиск объявляется доступным только при включённом провайдере и установленной схеме pgvector. Адреса провайдеров и токены не возвращаются.
- `GET /api/v1/admin/summary` дополнительно требует `is_admin`. Возвращает `item` с временем снимка, числом активных встреч/участников/записей, размером очереди, количеством отказов за 24 часа, состояниями API/media-worker и последними состояниями PostgreSQL, Redis, RabbitMQ и MinIO. Есть максимум десять недавних кодов ошибок. Идентификаторы пользователей и конференций, содержимое чата/транскриптов, job payload, SDP, пароли и токены отсутствуют.

Отказ авторизации: `401` без JWT, `403` для обычного пользователя. Если база недоступна при проверке права, маршрут закрывается с `500` без подробностей. Сводка читается по запросу, её счётчики приблизительны во время конкурентных изменений. Проверка media-worker ограничена 1,5 секунды и не раскрывает внутренний адрес.

`buildVersion` в Docker API задаётся безопасным `BUILD_VERSION` при сборке (короткий commit SHA или неизменяемый release ID). CI deploy передаёт `CI_COMMIT_SHA`; в production Compose аргумент обязателен. Для сборок вне Docker допускается безопасная версия Go binary или сокращённый VCS revision; при отсутствии метаданных возвращается `dev`.
